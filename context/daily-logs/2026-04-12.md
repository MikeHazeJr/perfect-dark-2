### Playtest Fix Batches
- **10-bug playtest batch (~01:48)** — commit `bc7bd7a5`, pre-Skin-Editor session.
- **Controller bindings (S218, ~11:35)** — Radial menu / weapon gear now accessible on gamepad. Root cause: D-pad was all C-button actions (legacy N64 look), so no gamepad button fired `ACTION_DPAD_*`. Fix: X=interact+reload dual-bind, Y=weapon cycle (was USE), DpadLeft=radial (was C-LEFT). A=jump, B=cancel/crouch unchanged. LB/RB remain weapon prev/next secondary.
- **File Browser + Skin Preview Fix (S219, ~16:42)** — new shared `pdgui_filebrowser.cpp/h` (+632 lines), controller-navigable, reusable by any importer. Hooked up in audio mod import and skin editor import. Also fixed 3D preview deadlock: `pdguiCharPreviewRenderGBI()` was bailing early when `curparams==0`, which prevented `menuRenderModel()` from ever loading the model. Classic circular dependency.
- **B-133 Inline Vp GBI Crash (S220, ~18:25)** — Fatal "Unknown GBI opcode 0x1ff02" during charpreview. Root cause: `pdguiCharPreviewRenderGBI()` embedded a `Vp` struct inline in the GBI display list; interpreter landed on Vp data as an opcode. Fix: `static Vp s_PreviewVp` — viewport data lives outside the display list; `gSPViewport` just stores a pointer. Also fixed `sysFatalError` format string in `gfx_pc.cpp` (added `<cinttypes>`, `PRIxPTR` for 64-bit `w0`/`w1`).
- **9-Issue Playtest Batch (S221, ~19:16)** — 5 files, +204/-225: Settings z-order (BeginChild wrapper), Cheats promoted to top-level tab, default controller bindings (LSTICK axes, C-buttons → right stick, D-pad Up/Right explicit, Fire Mode → DPAD_RIGHT), themes empty (`pdguiThemeLoaderInit()` was NEVER CALLED — added to `pdguiInit()`), catalog missing music (`AUDIOMOD_MAX_ENTRIES` 512→2048 — 1545 SFX were overflowing before 43 music tracks could load), Cheats tab snap-back (SetSelected firing every frame), Audio Mod Menu layout restructure (TOP=Pack Creator, MIDDLE=Export Track, BOTTOM=Import Audio), Import copy failure (`copyFile()` now resolves dest via `fsFullPath()`).
- **3 Audio Mod Playtest Fixes (S222, ~20:20–20:23)** — MP3 playback failure (format-specific loaders use raw `fopen()` with relative paths that fail when CWD ≠ data dir; fix: `fsFullPath()` resolution before passing to loaders, copied to stack buffer since `fsFullPath()` returns static pointer); import success feedback (timed green flash, 4s pulse); Select Music button in room Combat Sim tab (opens existing `g_MpSelectTunesMenuDialog`).
