## Changed / Decisions Made
- **NET_PROTOCOL_VER 36 → 37** — breaking bump accompanying B-12 Phase 3 chrslots retirement; SVC_STAGE_START `u64` slot-mask now derives from participant pool instead of `g_MpSetup.chrslots`. On-wire length unchanged.
- **D-MEM pool regions fixed** — PERMANENT/STAGE/POOL_8 now occupy non-overlapping address ranges. `mempGetStageFree` and `mempGetNextStageAllocation` previously read from the wrong pool array (`g_MempExpansionPools` vs. `g_MempOnboardPools`) and returned 0/NULL permanently — latent bug, silent.
- **modeldefLoad chokepoint validation** — torn-modeldef rejection moved from ~a dozen scattered defensive guards to a single `modeldefLoad()` sanity check. Every FIX-B.2 / FIX-B.3 caller now expects NULL on torn input and emits a WARNING.
- **Asset Provider — `romProviderHandle()` is internal** — new `assetprovider_internal.h` with explicit caller allowlist. Game code goes through `assetLoadRomToNew` or catalog handles, never raw filenums.
- **Discord RPC written from scratch** — rejected discord-rpc (C++/rapidjson dependency) and Discord Game SDK (DLL-only). Speaks named-pipe protocol directly.
- **Updater CA store** — MSYS2 libcurl lacks winstore integration; `CURLSSLOPT_NATIVE_CA` is a runtime no-op. Embedded Mozilla bundle chosen over shipping a `cacert.pem` file (zero-DLL and zero-config).
- **Font swap is live** — no more "restart required" hint. Atlas rebuild on `pdguiRequestFontAtlasRebuild()` flag in `pdguiNewFrame`.
- **Legacy sidecar migration is one-shot + idempotent** — pre-S313 sidecar files (sanitized `file->name` bytes) auto-rename to display-name path on first Agent Select load.
- **Subtitles are ImGui-native** — legacy `hudmsgsRender` subtitle path disabled. Bottom-center panel via `GetForegroundDrawList()` so cutscene letterbox bars don't occlude.
