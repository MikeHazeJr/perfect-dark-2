## What Was Added This Session

### Sound Mode dropdown
**Gap**: `g_SoundMode` / `sndSetSoundMode` was in CI Options but missing from unified Audio settings.

**Added to renderSettingsAudio** — new "Output" section after volume controls:
```cpp
/* Sound Mode (absorbed from CI Options) */
{
    s32 mode = g_SoundMode;
    if (mode < 0 || mode > 3) mode = 1; /* clamp; default = Stereo */
    const char *modeOpts[] = { "Mono", "Stereo", "Headphone", "Surround" };
    if (PdCombo("Sound Mode", &mode, modeOpts, 4)) {
        sndSetSoundMode(mode);
    }
}
```

**Extern declarations added** in extern "C" block (after g_MusicDisableMpDeath):
```cpp
extern s32 g_SoundMode;
void sndSetSoundMode(s32 mode);
```

SOUNDMODE_* values from src/include/constants.h:
- 0 = Mono, 1 = Stereo, 2 = Headphone, 3 = Surround
