### Item 4 -- ccache env propagation in devtools/build-env.sh

Added defensive re-exports of `HOME`, `USERPROFILE`, `LOCALAPPDATA`,
and `APPDATA` to `devtools/build-env.sh`. The Track E worker (commit
`8b8f55d7`) found that ccache silently swallows compiler stderr when
these env vars are missing from bash subshell environments; they
worked around by invoking ninja via a `.bat` wrapper in `cmd.exe`.

Pattern: `[ -z "$VAR" ] && export VAR="<default>"` -- idempotent;
no-op in a normal interactive shell where the variables already exist;
fixes the silent-stderr-swallow case when bash is launched from a
subshell that dropped them. `APPDATA` and `LOCALAPPDATA` derive from
`USERPROFILE` so they stay coherent if one was set and the other not.

Validated by sourcing the script:

```
$ source devtools/build-env.sh && echo "USERPROFILE=$USERPROFILE LOCALAPPDATA=$LOCALAPPDATA APPDATA=$APPDATA HOME=$HOME"
USERPROFILE=C:\Users\mikeh LOCALAPPDATA=C:\Users\mikeh\AppData\Local APPDATA=C:\Users\mikeh\AppData\Roaming HOME=/c/Users/mikeh
```

All four populated.
