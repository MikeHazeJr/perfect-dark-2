### Two same-day code fixes from the audit's top action items

**c128: catalog audio category seed russ-table fix.**

`port/src/assetcatalog_base_extended.c:624-685`. Sister bug to c106. The prior loop treated `g_AudioRussMappings[i]` as if `i` is a leaf SFX index, but the russ table is `confignum`-indexed (per `union soundnumhack` in `src/include/types.h:3484` + `propsnd.c::psGetTheoreticalVolPan` line 1409-1412). Fixed by building a `u8 voice_cache[NUM_BASE_SFX_ENTRIES]` bitset via russ-table forward walk + 11-bit `id` extraction, then having the leaf-SFX seed loop consult the bitset. PD_SERVER build short-circuits as before.

**c129: SWARM_GPU_MAX comment drift + B-311 safe-ceiling warning.**

`port/fast3d/swarm_gpu.cpp`. The `SWARM_GPU_MAX = 256` constant was documented with `/* must match TESTSCEN_SWARM_MAX_COUNT */`, but `TESTSCEN_SWARM_MAX_COUNT = 4096` per `testscenarios.h:45`. Rewrote the comment to acknowledge the 256 is an intentional cap pending GPU pipeline migration. Added `SWARM_GPU_SAFE_MAX = 64` + a rate-limited LOG_WARNING in `swarmGpuStepAndApply` so users see the B-311 workaround in-context instead of discovering it via crash.
