# Modding Examples

These examples use typed `*.pdxxx` content files as the authoring surface. Open and edit the typed descriptor directly, then edit the standard sidecar files next to it.

`.pdmod` is only the transport wrapper for Public Mods, online-required delivery, and sharing. Do not use `.pdmod` archives as the primary sample format, and do not add authored `*.bin` payloads.

## Available Sets

- `typed-pdxxx-basic/` - minimal head, arena, weapon animation, and character animation examples using GLTF, OBJ, and INI sidecars.
