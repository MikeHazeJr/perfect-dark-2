## Receipt contract and native gap

Pass requires an independently reviewed native receipt, not source validation.
The narrow model producer and its four-texture dependency extension have accepted
instrumented build/runtime proof for the exact CCTV cohort.
Other families need their own actual reads and completion witness.
Existing smoke receipts do not automatically imply per-asset attribution.
Missing attribution remains pending.

`--receipts receipt.json --binary-sha256 <SHA256> --source-sha256 <SHA256>` imports
the following explicit evidence envelope. Artifact paths resolve relative to
the receipt file and must stay under that directory. Every artifact is hashed;
one must be a structured native trace with schema `pd2.native-asset-consumer.v1`,
the same identity/generation/consumer/fallback/load/check fields as its envelope,
and nonempty `consumed_members` mapping actually read public source member paths
to their inventoried SHA-256. Packaging hashes do not assert consumption. Members
under `_meta/` alone cannot supply the source-use witness; optional authoring or
provenance files need not be consumed. Fidelity checks remain independently required.
An arbitrary log or screenshot renamed as a trace is rejected. Adapters unable
to attest actual reads stay pending.
Receipt checks are reviewed claims from the producer;
the ledger does not independently reproduce native behavior or authenticate a
producer. Preserve the original native receipts when adapting them.

The retained body/head `nested_first_owner` witness is archive admission/identity
evidence and explicitly records `nonresident=1`. Its digest uses the sorted-entry
`pd.weapon_graph.archive_content.v1` domain (`weapon_graph_archive.c:687`), not
the ledger's raw archive-file SHA-256, a model closure hash, or an individual
consumed member's SHA-256. It must not be copied into `consumed_members` or used
to promote native loading. The member-hash negative regression keeps such a
receipt pending. Actual model member bytes are captured by `readModel` in
`catalog_model_generation.cpp:73`; successful activation and separate family
behavior still need to be bound to that capture by a native producer.
